Rotate tenant key

    

        Asks the Bee Flow server for a fresh tenant key for the same organisation;
        the old key stops working at once. Use this if the current key is suspected
        leaked, or when rolling credentials as part of regular hygiene. If the
        rotation fails, the current key stays in use.
    

    

        
        
    

    






    
Nextcloud certificate

    

        Your Nextcloud uses a self-signed certificate. The connector trusted the first one it
        saw and only connects to Nextcloud while it presents that same key, so nobody in
        between can read the traffic. When the certificate is renewed with a new key, the
        connector stops and waits for you here.
    

    

    

        
        
    






    
Clear organisation cache & re-bootstrap

    

        Drops the cached organisation binding (tenant key) and re-bootstraps from
        scratch. Use this to recover when this Nextcloud is bound to a Bee Flow
        organisation that was deleted or recreated on the server — the symptom is
        that the app loads but every request fails with 401 or shows a
        sign-in screen. If the organisation still exists the connector re-binds to
        it; otherwise a fresh one is provisioned. The previous key is restored
        automatically if the re-bootstrap fails.
    

    

        
        
    

    






    
Tenant key diagnostic

    

        Run this when sign-in fails with “Connector token rejected: no matching tenant key”
        or you keep seeing 502 Bad Gateway on /api/*. The connector asks
        the SaaS what it has stored for this Nextcloud instance and compares fingerprints — no
        secret material is exposed.
